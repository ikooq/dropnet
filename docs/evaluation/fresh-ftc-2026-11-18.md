# Fresh-period FTC evaluation, 18 November 2026

This evaluation uses the rules already described in the original project: number IDs with at least two pre-2026-11-02 filings, plus six-digit ranges with at least five distinct non-matching-area-code reported numbers. Training is unchanged: 192,653 complaints filed before 2 November. The fresh test uses FTC files published 16 and 17 November, with parsed complaint filing dates 13–16 November, after the original snapshot's latest filing date of 12 November. The files and machine-readable result are included in this repository. Obtain the original daily files from [FTC Do Not Call reported calls](https://www.ftc.gov/policy-notices/open-government/data-sets/do-not-call-data).

| Rule set | All 29,549 new filings: matched | 21,834 new filings with valid call date in the new period: matched |
|---|---:|---:|
| Previously repeated numbers | 1,054 (3.57%) | 723 (3.31%) |
| Numbers plus geographic ranges | 3,896 (13.18%) | 2,578 (11.81%) |
| Numbers plus all ranges including toll-free | 5,910 (20.00%) | 3,963 (18.15%) |

The event-date subset excludes 7,631 filings concerning earlier reported call dates and 84 with a reported call date after filing. A filing-date match does not establish a call after the training cutoff. The geographic rule set covers approximately 28,730,391 possible numbers including number rules; legitimate-call volume and harm are unknown. Complaints and caller IDs are unverified; this is not fraud precision, recall, number of calls blocked, or causal impact. The data are only four filing days and this later-period test remains an exploratory evaluation; the original project and thresholds were designed using earlier data. Categories and inclusion are governed by the existing parser.

Reproduce from the repository root: `python scripts/evaluate_fresh_ftc.py --train-dir data/ftc/raw --test-dir data/ftc/fresh-2026-11-18`. The JSON lists SHA-256 hashes of decompressed source CSV bytes, making them independent of gzip metadata. The evaluation preserves both training and test files and does not modify the original saved graph or its web demo. Changes to an FTC file or the parser can change results; the original files are retained for this evaluation.
